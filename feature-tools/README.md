# 🎙️ Фича Инструменты

**Локальный голосовой диктовщик для macOS.** Зажимаете клавишу, говорите, отпускаете — и аккуратный, грамотный текст сам появляется в активном поле (или в буфере обмена).

Главный сценарий — **диктовка промтов голосом**: вы говорите хаотично, с паузами и повторами, а на выходе получаете чистый промт для ChatGPT, Claude и других AI.

- ✅ Работает **локально** на вашем Mac.
- ✅ **Без платных API.** Аудио и текст никуда не отправляются.
- ✅ Понимает **русский и английский**.
- ✅ Не просто транскрибирует, а делает текст грамотным.

---

## Что это и как работает (простыми словами)

1. Вы зажимаете горячую клавишу (по умолчанию **правый Option ⌥**).
2. Сервис записывает ваш голос.
3. Отпускаете клавишу — запись останавливается.
4. Локальная модель распознаёт речь (faster-whisper).
5. Текст улучшается: убираются «эээ», «ну типа», повторы; ставится пунктуация.
6. Результат копируется в буфер обмена и вставляется в активное поле.

Улучшение текста делает локальная нейросеть **Ollama** (если установлена). Если её нет — работает простая встроенная очистка. Ничего платного и облачного.

---

## Что нужно установить

1. **macOS** (Apple Silicon или Intel).
2. **Python 3.11 или новее.** Проверить: откройте Terminal и введите `python3 --version`.
   Если старый или его нет — поставьте через [Homebrew](https://brew.sh): `brew install python@3.12`.
3. **ffmpeg** (для надёжной обработки звука): `brew install ffmpeg`.
4. *(Необязательно)* **Ollama** для умного улучшения текста — [ollama.com](https://ollama.com).

## Установка

Откройте приложение **Terminal** и выполните по очереди:

```bash
cd путь/до/проекта/feature-tools
chmod +x install.sh run.sh
./install.sh
```

Скрипт сам проверит Python, создаст окружение, поставит зависимости и подскажет, если чего-то не хватает. Если увидите сообщение про ffmpeg или Ollama — это подсказки, а не ошибки.

*(Необязательно)* Чтобы включить умное улучшение текста:

```bash
ollama pull qwen2.5:7b
```

## Как запустить

```bash
./run.sh
```

Вы увидите: **«Фича Инструменты запущен. Зажмите горячую клавишу и говорите».**

Теперь зажмите **правый Option ⌥**, скажите фразу, отпустите — и через пару секунд текст появится там, где стоит курсор.

Для выхода нажмите **Ctrl+C** в окне Terminal.

---

## Как пользоваться

1. Поставьте курсор в любое текстовое поле (ChatGPT, заметки, мессенджер).
2. Зажмите горячую клавишу и говорите.
3. Отпустите клавишу.
4. Текст вставится сам. Если нет — он уже в буфере, нажмите **Cmd+V**.

В окне Terminal вы каждый раз видите:
- **черновую транскрибацию** (что распозналось),
- **улучшенный текст** (что получилось),
- **статус вставки**.

## Режимы тестирования (без горячей клавиши)

**Проверить улучшатель текста на примере** (микрофон не нужен):

```bash
./run.sh --test-text
```

**Записать один раз с микрофона** (управление через Enter):

```bash
./run.sh --record-once
```

Нажмите Enter — начнётся запись; скажите фразу; нажмите Enter ещё раз — запись остановится, текст распознается, улучшится и попадёт в буфер.

**Посмотреть список микрофонов:**

```bash
./run.sh --list-devices
```

## Настройка (файл `config.yaml`)

Откройте `config.yaml` любым текстовым редактором. Самое важное:

| Настройка | Что меняет | Варианты |
|---|---|---|
| `hotkey` | горячая клавиша | `right_option`, `left_option`, `f18`, `right_ctrl` … |
| `language` | язык | `auto`, `ru`, `en` |
| `whisper_model` | качество распознавания | `tiny`, `base`, `small`, `medium` |
| `paste_mode` | куда отдавать текст | `auto_paste`, `clipboard_only`, `both` |
| `use_ollama` | улучшать ли нейросетью | `true` / `false` |
| `ollama_model` | модель Ollama | `qwen2.5:7b` … |
| `text_mode` | стиль обработки | `raw`, `clean`, `prompt_writer`, `letter`, `note` |

После изменения настроек перезапустите сервис: `Ctrl+C`, затем снова `./run.sh`.

### Как поменять горячую клавишу

В `config.yaml` измените строку `hotkey:`. Например, на `f18` или `left_option`. Сохраните файл и перезапустите сервис.

> ⚠️ **Про одиночный Control.** Использовать одиночный Control как «зажми и говори» на macOS ненадёжно: система и многие приложения перехватывают сочетания с Control (например, для эмодзи, переключений, спецсимволов), поэтому отпускание клавиши не всегда ловится корректно. Поэтому по умолчанию стоит **правый Option ⌥** — он почти нигде не используется и работает стабильно. Если очень нужен Control — попробуйте `right_ctrl` (правый), он мешает меньше левого, но Option всё равно надёжнее.

### Стили обработки текста (`text_mode`)

- **`raw`** — почти сырая транскрибация, минимум правок.
- **`clean`** — починить грамматику и пунктуацию, оставаясь близко к сказанному.
- **`prompt_writer`** *(по умолчанию)* — оформить речь как аккуратный промт для AI.
- **`letter`** — оформить как вежливое письмо.
- **`note`** — оформить как короткую заметку/список.

## Если что-то не работает

### ❌ Нет доступа к микрофону
macOS блокирует микрофон, пока вы не разрешите. Откройте:
**System Settings → Privacy & Security → Microphone** → включите **Terminal** (или ваш терминал). Перезапустите `./run.sh`.

### ❌ Не работает автовставка (текст только в буфере)
macOS требует разрешение на «управление компьютером». Откройте:
**System Settings → Privacy & Security → Accessibility** → включите **Terminal**.
Пока не включите — текст всё равно будет в буфере, вставляйте вручную **Cmd+V**. Это не поломка.

### ❌ Горячая клавиша не реагирует
Нужен доступ к отслеживанию клавиатуры:
**System Settings → Privacy & Security → Input Monitoring** (и **Accessibility**) → включите **Terminal**. Перезапустите сервис.

### ❌ Текст распознаётся плохо
- Говорите ближе к микрофону, без сильного шума.
- В `config.yaml` поставьте модель получше: `whisper_model: "medium"` (медленнее, но точнее). Для слабого Mac — `base` или `small`.

### ❌ Хочу умное улучшение текста
Установите [Ollama](https://ollama.com), затем `ollama pull qwen2.5:7b` и убедитесь, что в `config.yaml` стоит `use_ollama: true`. Проверьте: `./run.sh --test-text`.

---

## Как включить Ollama (умное улучшение)

1. Установите Ollama с [ollama.com](https://ollama.com).
2. Скачайте модель: `ollama pull qwen2.5:7b`.
3. В `config.yaml`: `use_ollama: true` и `ollama_model: "qwen2.5:7b"`.
4. Запустите `./run.sh --test-text` — должно быть написано «Ollama доступна».

Если Ollama выключена или недоступна, сервис не падает, а использует встроенную простую очистку.

## История диктовок

Последние 20 диктовок сохраняются локально в файл `history.jsonl` (рядом с проектом). Чтобы **не сохранять историю**, поставьте в `config.yaml`:

```yaml
save_history: false
```

## Как полностью удалить проект

Всё хранится в одной папке. Достаточно её удалить:

```bash
rm -rf путь/до/проекта/feature-tools
```

Дополнительно (по желанию):
- Скачанные модели Whisper лежат в `~/.cache/huggingface` — можно удалить.
- Если ставили Ollama и она не нужна — удалите её отдельно через её инструкции.
- Уберите разрешения в **System Settings → Privacy & Security** (Microphone / Accessibility / Input Monitoring), если давали их Terminal только ради этого проекта.

## Ограничения macOS (честно)

- **Разрешения.** macOS обязательно спросит доступ к микрофону, мониторингу клавиатуры и Accessibility. Без них сервис не сможет слышать клавишу, писать звук или вставлять текст. Это требование системы, обойти его нельзя — нужно один раз включить галочки в System Settings.
- **Одиночный Control** как hold-to-talk нестабилен (см. выше) — поэтому по умолчанию правый Option.
- **Первый запуск** скачивает модель распознавания — нужен интернет один раз. Дальше всё работает офлайн.
- **Скорость.** На слабых Mac модель `medium` может думать несколько секунд. Для скорости используйте `small` или `base`.
